# Technical Overview

## What is Blackboard?
Blackboard is a widely used web-based virtual learning environment and learning management system (LMS) 
that helps schools and organizations manage online and hybrid courses. Students use Blackboard to read
course materials, check their grades, reply to class-wide discussions, and submit assignments to their
professors. In this documentation we will be focusing on submitting assignments. It is the most important
function of Blackboard that students need to utilize the most.
