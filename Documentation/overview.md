# Technical Overview

## What is Blackboard?
Blackboard is a widely used web-based virtual learning environment and learning management system (LMS) 
that helps schools and organizations manage online and hybrid courses. Students use Blackboard to read
course materials, check their grades, reply to class-wide discussions, and submit assignments to their
professors. In this documentation we will be focusing on submitting assignments. It is the most important
function of Blackboard that students need to utilize the most.

## Important Terms and Ideas
File Types: In this documentation I will primarily refer to two different file types .docx and .pdf. Most
assignments that are submitted use these two file types. They are the most common however, there are more 
but they will not be referred to in this documentation. It is important to know these tow and the differences 
they have.
 - **.docx**: This is a popular word processing document format created by Microsoft and primarily pertains to WORD
   documents. .docx formatting is typically used for documents such as essays and long form writing assignments.
 - **.pdf**: Portable Document Format, a universal file type that keeps text, fonts, and images locked in place so a
   document looks identical on any device or operating system. This is typically used for assignments that incoporate
   both text and images.

File Explorer: It is the built-in file management application in Windows used to view, organize, and manage files, folders,
and drives on a computer This is where blackboard takes you when you are trying to upload a file. We will be mostly focused
on the downloads folder as this is where most of the documents you are going to submit will be.

Upload: To upload a file simply means sending a digital copy of a file from your personal device to a server where it is then 
stored and can be viewed. This is how you are sending your assignments to your professor.
