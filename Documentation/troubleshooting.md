# Frequently Asked Questions

Here are some frequently asked questions and the answers to them!

- "How Do I know if my file is the correct type?"
  
  To check for this open File explorer on your computer. Go to
  downloads. Right-click on your desired file. Click on the "Properties"
  button that will show up. It will then open a new small window with all
  of the file information and you will see "Type of File:" followed by the file
  type. Remember that most submissions will require .pdf or .docx files!

- "What if I only need to submit a text response?"
  
  In the text box when you reach the turn-in page for the assignment
  all you need to do is type your response in the text box and submit!

- "What if I submitted the wrong document?"
  
  Some assignments have multiple tries to submit. If this is the case follow the
  process and submit again. Blackboard will take your most recent submission!
  If this is not the case make sure to email your professor right away!

- "What if my file won't upload?"
  
  This means that the file is either in the wrong format (refer to our answer
  to "How do I know if my file is the correct type") or corrupted. If the file
  is corrupted just simply go to your document and download it in the preferred
  format and try to submit again. If this doesn't work I'd then suggest an alternative
  method of submitting such as email.
