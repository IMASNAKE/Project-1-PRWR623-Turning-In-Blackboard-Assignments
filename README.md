# Project-1-PRWR623-Turning-In-Blackboard-Assignments

This repository serves as a step-by-step guide for unfamiliar and new first year English students turn-in their assignments correctly using the Blackboard program

### Intended Audience
The intended audience of this repository is first-year English 101 students who are unfamiliar to the Blackboard program.

### The Communication Problem and Document Purpose
First-year English students can have difficulty submitting an assignment correctly. This can be due to a multitude of factors
such as being unfamiliar with the program, being non-tech savvy, or being overwhelmed with the new changes college brings.
Blackboard itself does not provide enough resources to help the average new student with submitting assignments. This guide will
implement a step-by-step procedure that shows students how to:

- How to find an assignment
- How to upload a Word document or PDF
- How to click "Submit Assignment"
- How to confirm the submission

This guide will also provide troubleshooting help to further clarify any confusion or errors that a student might make when submitting.
Questions that would be answered are:

- “What if my file won't upload?"
- "What if I submitted the wrong file?"
- "How do I know my professor received it?"
- "What if Canvas says my assignment is missing?"
